• Fixed: Scan tasks now picks up every screenshot you take while it is capturing, also in a raid, and also when the game still thinks you are in a raid. Before, those screenshots could be missed or even deleted as position screenshots, with a false "Raid over".
• New: a separate task list for each game mode (PvE, PvP, PvP Season). Your existing list is kept for the mode that Settings had when you first open 2.9.0. The other two start empty: scan them. A copy of your old data file is kept.
• New: task updates from the game go to the mode you are playing, even when another mode is shown. Raid end resets only that mode's Bring counts. A scan changes only the list of the mode that is shown.
• New: in a squad, your friends' tasks show only when you are on the same game mode as they are. Drawings always show.
• New: the app opens on a Game mode page with a card for PvE, PvP and PvP Season: task counts, when you last used it, and which mode the game is in. Then come the maps. Links like "PvE / Maps / Customs" at the top lead back, and on a phone a "‹ Maps" link does.
• Note: after updating, going back to an older version will not read the new data file correctly. The old copy is in squad-task-map-data.v2-backup.json.
